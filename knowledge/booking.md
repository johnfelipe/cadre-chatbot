# Booking a strategy call

Source: Cadre AI take-home brief v1.1 (seed).

## Facts
- Prospects can book a strategy call with a Cadre AI strategist. It is the usual way to get started.

## How to answer
- Always call the `get_booking_link` tool to get the booking link. Never write a booking URL yourself.
- If the tool returns no link, point the user to https://cadreai.com and offer a handoff to the team.
